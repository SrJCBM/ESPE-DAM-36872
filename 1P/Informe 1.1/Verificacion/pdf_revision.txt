Instalación y configuración del SDK de Flutter y Android Studio
El desarrollo de aplicaciones móviles requiere un entorno que permita escribir código,
resolver dependencias, compilar y ejecutar pruebas en un dispositivo. Julio Blacio, Kerly Chuqui
y Josue Guayasamin desarrollaron este trabajo de manera conjunta. El grupo organizó el
procedimiento de instalación del SDK de Flutter y de Android Studio en Windows, revisó la
configuración de las herramientas de Android y documentó la comprobación del entorno
mediante una aplicación inicial.
El informe reunió el procedimiento y los resultados como parte de la práctica grupal. Las
evidencias se organizaron por comprobación y debajo de cada figura se identificó el equipo del
que procedió la captura.
Objetivos de aprendizaje
Objetivo general
Configurar un entorno de desarrollo de aplicaciones móviles con Flutter y Android Studio
en Windows, y comprobar su funcionamiento mediante la ejecución de una aplicación en
Android.
Objetivos específicos
1. Identificar la función del SDK de Flutter, el SDK de Android y el entorno de desarrollo
integrado.
2. Establecer la ruta de Flutter en la variable de entorno Path.
3. Preparar Android Studio, los complementos de Flutter y Dart, y las herramientas del SDK de
Android.
4. Verificar licencias, disponibilidad del dispositivo y ejecución de un proyecto inicial.
5. Documentar cada comprobación con capturas y registrar las incidencias encontradas.

Marco teórico
Flutter y Dart
Flutter es un conjunto de herramientas para el desarrollo de interfaces y aplicaciones
multiplataforma. Dart es el lenguaje utilizado para escribir la lógica y los componentes de estas
aplicaciones. El SDK de Flutter reúne las herramientas necesarias para trabajar con el proyecto y
proporciona acceso a las herramientas de Dart. Su instalación se verifica desde la terminal con los
comandos de versión (Flutter, s. f.-b).
Android Studio y el SDK de Android
Android Studio es el entorno de desarrollo integrado para Android. El SDK de Android
contiene las plataformas y herramientas utilizadas en la compilación y comunicación con
dispositivos. El IDE y el SDK cumplen funciones distintas: la interfaz del editor no sustituye los
paquetes que requiere una aplicación para compilarse (Android Developers, s. f.).
Integración del entorno
El complemento de Flutter incorpora al IDE funciones de edición, creación de proyectos y
ejecución. Su instalación no sustituye la descarga del SDK de Flutter (Flutter, s. f.-a,s). La
variable Path permite localizar los ejecutables desde una terminal. Por su parte, un dispositivo
virtual Android (A VD) define un entorno de prueba administrado desde Android Studio; también
puede utilizarse un teléfono compatible.

ejecutar la aplicación desde el IDE (Flutter, s. f.-a).

una carpeta de trabajo. Se debe emplear una sola de las dos vías de creación para evitar duplicar el
proyecto:
flutter create prueba_flutter
cd prueba_flutter
flutter run -d ID_ANDROID
